# Как добавлять скрытые SEO-статьи

SEO-статьи **не появляются на главной и в разделе «Статьи»**, но открыты для Google и других поисковиков. Их находят по прямым ссылкам и через sitemap.

Основная площадка — **WordPress на Hostinger**. Статика на GitHub Pages тоже поддерживает `/seo/`.

---

## WordPress (рекомендуется для сотрудников)

### Новая статья с нуля
1. Зайдите в `/wp-admin` → **Записи → Добавить**
2. Напишите заголовок и текст (таблицы можно вставлять HTML-блоком)
3. Справа в блоке **Secret Room — оформление** выберите формат  
   **SEO (скрытая, только поиск)**
4. Заполните SEO-заголовок (до ~60 символов) и описание (до ~160)
5. Нажмите **Опубликовать**

Статья получит адрес вида `/seo/ваш-ярлык/` и **не** попадёт на главную / в ленту.

### Импорт трёх готовых гайдов
1. **Инструменты → Secret Room: SEO**
2. Кнопка **Импортировать SEO-статьи**
3. После деплоя темы v1.4+ один раз зайдите в  
   **Настройки → Постоянные ссылки → Сохранить** (чтобы заработали URL `/seo/…`)

### Что не делать
- Не ставьте SEO-статьи «В герое на главной»
- Не выносите их в обычное меню
- Инструкции вроде «ПЕРЕЛИНКОВКА», «Для верстки», списки alt-тегов из черновиков в текст **не копируйте** — они для редактора, не для читателя

---

## Статика (GitHub Pages / демо-админка)

1. Откройте `admin.html` (пароль `secret2026`)
2. Создайте пост, тип **SEO (скрытая — только поиск)**
3. При публикации скачается HTML-файл
4. Положите его в папку `seo/` репозитория
5. Добавьте URL в `sitemap.xml` и запись в `js/data.js` → `SRM_SEO_ARTICLES`

---

## Проверка
- Главная и `/articles/` — статьи **нет**
- Прямой URL `/seo/…` — открывается, в `<head>` есть `index,follow` и description
- В `sitemap.xml` (статика) или в скрытом блоке подвала (WP) — ссылка есть
